# Programming Languages Portfolio

A beginner-friendly collection of small programs and web projects in several programming languages.

## Languages and projects

| Folder | Language | Project |
|---|---|---|
| `java/` | Java | Console calculator |
| `html-css/` | HTML + CSS | Personal portfolio page |
| `javascript/` | JavaScript | To-do list |
| `php/` | PHP + MySQLi | Simple student registration |
| `python/` | Python | Number guessing game |
| `c/` | C | Basic calculator |
| `sql/` | SQL | Student database setup |

## How to run

- **Java:** Install a JDK, open a terminal in `java/`, then run `javac Calculator.java` and `java Calculator`.
- **HTML/CSS:** Open `html-css/index.html` in your browser.
- **JavaScript:** Open `javascript/index.html` in your browser. The app runs in the browser without a server.
- **PHP:** Install XAMPP, copy the `php` folder into `htdocs`, start Apache and MySQL, create the database using `sql/students.sql`, then visit `http://localhost/php/`.
- **Python:** Install Python 3 and run `python guessing_game.py` from `python/`.
- **C:** Compile with a C compiler, for example `gcc calculator.c -o calculator`, then run the generated program.
- **SQL:** Run `sql/students.sql` in MySQL or phpMyAdmin.
